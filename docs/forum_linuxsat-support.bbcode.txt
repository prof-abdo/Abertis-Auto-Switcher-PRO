Hello everyone,

I am pleased to share my plugin Abertis Auto Switcher PRO – a complete automation suite for every Abertis feed on 30.0° W (Hispasat), built and tested live on a Dreambox Two – under [B]DreamOS 2.6 (Python 2.7)[/B] and under [B]openATV 8.0.1 (Python 3.14)[/B].

[SIZE=4][B]What does it do?[/B][/SIZE]

On 30.0° W the Abertis muxes broadcast dozens of FTA/BISS channels bundled inside one T2‑MI multiplex. Every feed appears as a separate PIDs mask (Abertis PID 301 / 303 / 420 / 2025 / 2026 / 2050 / 8001 / 8008 …). Normally you must re‑configure astra‑sm, oscam.dvbapi, SoftCam.Key and lamedb for every feed, by hand, every time the feed changes. This plugin does it with one click – or automatically on every boot.

[B]Automatic sequence (F1 → F5):[/B] when you zap any Ciefp streamrelay URL of the form http://127.0.0.1:8001/abertis/pid<NUMBER>, the plugin:
[LIST=1]
[*]Reads /etc/enigma2/lamedb and finds the service reference of "Abertis PID <n>", with its outer PMT PID and data PID c:00xxxx
[*][B]Learning phase (F1)[/B] – switches the service to F1, caches the data PID + PMT PID, reloads lamedb so the CA program is recognized
[*][B]Playback (F5)[/B] – switches back to F5 + cached data PID, reloads again – picture plays
[*]Everything is logged in real time, backed up first, and idempotent – run it a thousand times, nothing is duplicated or corrupted
[/LIST]

[B]Also automatic:[/B]
[LIST]
[*]One OSCam‑EMU [B]A: rule per feed[/B] in /etc/tuxbox/config/oscam.dvbapi (backup kept)
[*]Mirrors missing BISS keys between softcam.key and SoftCam.Key (oscam‑emu reads the uppercase file)
[*]Generates missing astra‑sm stream blocks in /etc/astra/astra.conf
[*]Writes /etc/init.d/astra + astra-sm.service: astra starts at every cold boot (only when the image does not already manage astra)
[*]lamedb fix [B]before[/B] Enigma2 starts (systemd ExecStartPre drop‑in) – no more lost c:00xxxx data PIDs after a rescan
[*]"Ta9ti3" (picture cutting) fix: /etc/sysctl.d/99‑abertis.conf with 16 MB UDP socket buffers – no more packet loss on the streamproxy → astra hop
[/LIST]

[SIZE=4][B]What is new in v1.9.13[/B][/SIZE]
[LIST]
[*][B]Both image families[/B]: DreamOS / Debian images (dpkg) install the [B].deb[/B]; OpenATV / OpenPLi / opkg images install the [B].ipk[/B] – the one‑line installer detects the package system automatically.
[*][B]One package for every receiver architecture[/B]: it detects uname ‑m and deploys the matching binaries:
   ‑ aarch64/arm64: full toolchain (astra, t2mi_decap, spammer, abertis)
   ‑ arm (32 bit) and mips: static native abertis de‑encapsulator
[*][B]Wrong‑architecture binaries are never deployed[/B]: on arm/mips your already‑installed binaries are kept untouched, only the abertis tool of that architecture is deployed (logged).
[*][B]Images without OpenSSL 3 cannot receive a broken astra[/B]: the patched astra is linked against libcrypto.so.3. When the image lacks it (e.g. openATV 8.0.1 ships libcrypto.so.4/1.0.2), the library carried by the package is deployed into /usr/lib [B]only when missing[/B] and ldconfig is refreshed – if a needed library can neither be found nor shipped, our binary is not installed and [B]your working one stays[/B]. Every replaced file is kept once as *.orig.
[*]The installer never reboots and never restarts Enigma2 – the plugin loads at the next Enigma2 start of your choice.
[/LIST]

[SIZE=4][B]Nothing is ever overwritten[/B][/SIZE]
/etc/astra/astra.conf, /etc/astra/scripts/abertis, the OSCam files and your working softcam keys are never overwritten: only missing entries are appended, everything backed up first (.orig / .abetrisauto.bak / /root/abetris‑backup). The Abertis keys are shipped as *.dist so fresh images descramble out of the box while existing receivers keep their keys.

[SIZE=4][B]Installation (one line, root shell, both images)[/B][/SIZE]
[CODE]wget https://raw.githubusercontent.com/prof-abdo/Abertis-Auto-Switcher-PRO/main/installer.sh -O - | /bin/sh[/CODE]

Manual install:
[CODE]# DreamOS / Debian images (dpkg):
cd /tmp
wget -O abertis-pro.deb https://github.com/prof-abdo/Abertis-Auto-Switcher-PRO/releases/download/v1.9.13/enigma2-plugin-extensions-abertisautoswitcher_1.9.13_all.deb
dpkg -i abertis-pro.deb

# OpenATV / OpenPLi / opkg images:
cd /tmp
wget -O abertis-pro.ipk https://github.com/prof-abdo/Abertis-Auto-Switcher-PRO/releases/download/v1.9.13/enigma2-plugin-extensions-abertisautoswitcher_1.9.13_all.ipk
opkg install --force-reinstall --force-overwrite abertis-pro.ipk[/CODE]

Menu: [B]Menu → Extensions → AbertisAutoSwitcher[/B] (manual "Run setup", auto‑sequence runs on every boot and every Ciefp URL zap).

[SIZE=4][B]What you need[/B][/SIZE]
[LIST]
[*]An Enigma2 image with dpkg (DreamOS 2.6) or opkg (OpenATV 8 / OpenPLi)
[*]A dish on 30.0° W and one free tuner (Hispasat 12583 V, T2‑MI multiplexed)
[*]OSCam with oscam‑emu installed
[*]The Ciefp streams/bouquets providing the /abertis/pid<n> URLs
[/LIST]

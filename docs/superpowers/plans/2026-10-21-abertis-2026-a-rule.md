# Abertis PID 2026 A-Rule / F5 Automation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make PID 2026 automation use the live-verified OSCam-EMU `A:` rule and F5 only, while preserving the other Abertis service rules.

**Architecture:** Setup idempotently backs up and adds the exact A-rule to `oscam.dvbapi`, restarting only a uniquely identified active OSCam systemd unit when the rule is newly added. The 2026 state machine then applies F5 only, reads Astra's TS to synchronize streamrelay PIDs, and plays with the discovered PMT PID.

**Tech Stack:** DreamOS Python 2.7-compatible plugin code; standard-library `unittest`; existing `build_ipk.py` package builder.

**Spec:** User-approved conversation requirements (checkpoint summary; no separate spec file): the tested rule is `A: ::0BD2:07EA 2600:000000:1FFF`; PID 2026 must never enter F1; 8001/2050 remain F1+data+PMT; other services and the OSCam binary remain untouched; do not deploy to the receiver.

## Global Constraints

- PID 2026 uses F5 + data PID only in `lamedb`; no F1 acquisition step and no PMT cached there.
- PID 8001 and PID 2050 remain F1 + data PID + PMT; other Abertis entries remain untouched.
- Add only the verified PID 2026 `A:` rule; preserve all existing `oscam.dvbapi` content and create a backup before editing an existing file.
- Never replace the OSCam binary, edit `/etc/astra/astra.conf` or key files, issue rotor commands, or deploy the package to the receiver.
- Keep production code compatible with DreamOS Python 2.7; local tests run with the available Python 3 `unittest`.
- The streamrelay path must use the PMT discovered from Astra's PAT: SID `0x020C` maps to PMT PID `0x012C` in the verified feed.

## Review Focus

- Existing matching A-rule (including case/comment variation): installer must be idempotent and must not rewrite or restart OSCam.
- Missing `oscam.dvbapi`: create the config with the rule; do not invent a backup of a nonexistent file.
- Zero or multiple active OSCam systemd units: skip restart rather than guessing; report the reason.
- A F5 transition: only the 2026 record may change; preserve 8001, 2050, and unrelated Abertis records.
- Playback failure while the previous service may be on another satellite: do not automatically zap back; leave any retune to the user to avoid moving the manual motor.
- TS bytes on Python 2 and Python 3: parse PAT/PMT safely and place PMT `0x012C` in the existing streamrelay reference field without changing its URL.
